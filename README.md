# End-to-End Salary Prediction Application 🚀

An interactive Machine Learning web application built using **Streamlit** and deployed on **Streamlit Community Cloud**. This project predicts a professional's salary based on their years of experience.

##  Project Features
- **Interactive UI:** Dynamic numerical inputs for user data.
- **Serialized Model:** Fast prediction generation using a pre-trained, serialized model (`model.pkl`).
- **Clean Interface:** Beautiful and easy-to-use layout for users.

##  Project Structure
├── data/               # Raw dataset folder
│   └── data.csv        # Salary Dataset file
├── model.pkl           # Serialized ML model artifact
├── model.ipynb         # Jupyter Notebook for EDA and model training
├── app.py              # Core Streamlit application code
├── requirements.txt    # Python library dependencies
└── README.md           # Project documentation
